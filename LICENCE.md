## 🧩 About

**REANIMAL Companion** is a curated list of REANIMAL open-source tools:

- **Overlays** — on-screen helpers, layout notes, route viewer, checkpoint tracker
- **Quality-of-Life Helpers** — item catalog, inventory notes, overlay notes
- **Research Notes** — level layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Checkpoint Tracker — review progress from any save point
- Route Viewer — visualize level paths for study
- Run Notes — record and review exploration runs
- Playback Speed — adjust study playback (0.1x to 5x)

### Wallhack
- Item Catalog — browse items, colors, and effects
- Custom Skin Notes — organize player cosmetics
- Visibility Notes — improved marker visibility

### Aimbot
- Practice Notes — segment study on any layout
- Movement Helper — manually adjust movement for study
- Timing Notes — chain complex maneuvers in the editor
